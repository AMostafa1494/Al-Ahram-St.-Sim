# Heliopolis Traffic Microsimulation — محاكاة مرور مصر الجديدة

Interactive agent-based traffic microsimulation for a 1 km-radius district around
**Al-Ahram Street, Heliopolis, Cairo** — built on the real OpenStreetMap network.

- **Routing:** A* (time-shortest) · **Car-following:** Intelligent Driver Model (IDM)
- Up to 5,000 vehicles · live congestion heatmap · zoom & touch
- Interactive: open/close streets, change directions, before/after Al-Ahram closure
- Auto-optimizer: converts congested arterials to one-way + side-street couplets
- Calibrated to real Cairo speed averages (TomTom ~21 km/h peak; World Bank 20–45 km/h)

Single self-contained `index.html` (all OSM data embedded, no external requests).

By CUBE Consultants.
